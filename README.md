# landing-page

A lightning-fast, mobile-responsive landing page engineered specifically for high conversion rates, seamless user experience, and top-tier Google Core Web Vitals performance.

##  Key Highlights
* **Performance-First Architecture:** Lightweight, dependency-free vanilla CSS and JavaScript with zero heavy frameworks.
* **Technical SEO Integration:** Includes structured Schema.org JSON-LD data, Open Graph social tags, and semantic HTML5 landmarks.
* **Conversion Rate Optimization (CRO):** Clean visual hierarchy, prominent calls to action, and distraction-free layout.

## 📂 Files
* `index.html` - Semantic markup & structured metadata.
* `style.css` - Responsive layout, CSS variables, and modern design system.
* `script.js` - Lightweight interaction handling.
